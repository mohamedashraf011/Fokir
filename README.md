# Fokir — Personal Portfolio Template

Fokir is a **static personal portfolio website** built using **pure HTML and CSS**.  
It’s designed as a simple, elegant personal homepage to showcase information, services, portfolio items, and blog posts.  
This project focuses on clean layout and well-structured code rather than interactivity or responsiveness.


---

## Project Sections

- **Home:** Header section with background image and introduction text.  
- **About:** Profile section with image, description, and personal information table.  
- **Services:** Four service cards showing professional skills or specialties.  
- **Portfolio:** Image gallery displaying sample works.  
- **Statistics:** Section showing numbers and achievements.  
- **Feedback:** Simple testimonial area.  
- **Blog:** Three posts, including image and YouTube video embeds.  
- **Contact:** Form layout (non-functional) and social media icons in the footer.

---

## Built With
- **HTML5** for structure  
- **CSS3** for layout and styling
